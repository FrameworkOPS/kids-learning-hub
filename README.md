# Kids Learning Hub

A fun, interactive learning dashboard for kids. Built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- **Kid Profiles**: Switch between learner profiles with personalized themes.
- **Math Practice**: Adaptive difficulty, streaks, points, and instant feedback.
- **Handwriting**: Canvas-based tracing for letters, numbers, and words with star ratings.
- **Reading & Writing**: Leveled reading passages with comprehension questions and creative writing prompts.
- **Progress Reports**: Visual reports and tutoring insights powered by local activity data.

## Tech Stack

- React 19 + TypeScript
- Vite 7
- Tailwind CSS 3 + shadcn/ui components
- Framer Motion
- Recharts
- Local storage for progress persistence

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Build

```bash
npm run build
```

The production build is output to the `dist/` directory.

## Deployment

This is a static Vite site. Deploy the contents of `dist/` to any static host (e.g., GitHub Pages, Railway, Vercel, Netlify).
